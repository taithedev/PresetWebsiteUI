01 / GETTING STARTED

Ready in seconds.

This is a static, dependency-free site. You do not need Node, a bundler, a database, or an API key to run it.

01

Get the source

Download or clone the repository. All HTML, CSS and JavaScript files are committed in the project root.

02

Open the site

Open index.html in a browser, or serve the folder with any static file server. Navigate to docs.html for this guide.

03

Customize

Edit the variables at the top of styles.css, or visit the playground and copy a custom CSS token set.

02 / FOUNDATIONS

Design principles.

Preset UI intentionally combines atmosphere with legibility. The goal is a distinctive interface, not a wall of blur.

01 — Depth

Use a deep neutral canvas, subtly lifted cards, hairline borders and crisp highlights. Layers must remain distinguishable.

02 — Light

Glows should have a source. Combine diffused ambience behind objects with carefully contained edge lighting.

03 — Rhythm

Consistent spacing, purposeful typographic hierarchy and restrained repetition make ambitious visuals usable.

04 — Feedback

Motion should explain relationships or acknowledge input, not interrupt tasks. Honor reduced-motion preferences.

04 / FOUNDATIONS

Type makes the difference.

Use Space Grotesk for display headings and DM Sans for UI and body copy. System font fallbacks keep the page readable if font hosting is unavailable.

DISPLAY / SPACE GROTESK 600Make it matter.
BODY / DM SANS 400

Every interaction is an opportunity to build trust through clarity and restraint.

Suggested spacing scale: 4, 8, 12, 16, 24, 32, 48, 64, 96. Use responsive typography with clamp() and a maximum content width around 1240px.

07 / EFFECTS

Bloom without blur overload.

Use three separate layers: ambient blur behind the object, a directional highlight on the surface, and a low-opacity glow around the perimeter. Never blur text or form controls.

✳LIGHT SOURCE / 01
CSS / AMBIENT LIGHT
.glow-scene { position: relative; isolation: isolate; }
.glow-scene::before {
  content: "";
  position: absolute;
  inset: 12%;
  z-index: -1;
  border-radius: 50%;
  background: rgb(var(--accent-rgb) / 0.6);
  filter: blur(55px);
  opacity: calc(var(--bloom) * 0.72);
  pointer-events: none;
}
/* Animate transform or opacity, not expensive blur radius. */
@media (prefers-reduced-motion: reduce) {
  .glow-scene::before { animation: none; }
}

Recommended animation timing: 180–320ms for hover and focus, 500–800ms for section entrances, and 6–12s for nonessential ambient movement. Use transform and opacity where possible.

08 / RESPONSIVENESS

Designed to adapt.

Layout rules in the source use flexible grids and viewport breakpoints rather than fixed screenshot dimensions. Preserve the reading order and remove decorative layers before sacrificing useful content.

≤ 660pxSingle-column presets, compact header, mobile menu
661–900pxStacked hero and studio, two-column cards
901–1150pxCompact desktop grids and scaled art
1151px+Full composition, three-column gallery
09 / QUALITY

Make it usable.

Premium aesthetics are incomplete if they cannot be navigated. The reference implements keyboard-accessible links and buttons, native modal focus handling, status announcements, visible focus rings, skip navigation, and reduced-motion support.

  • Use real buttons for actions and real links for navigation.
  • Keep text contrast adequate, especially over glows and gradients.
  • Honor prefers-reduced-motion: reduce.
  • Use label elements for inputs and announce dynamic status.
  • Never hide functionality behind hover-only UI.
  • Test at 320px width and using keyboard-only navigation.
