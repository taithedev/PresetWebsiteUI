# Standalone examples

These examples show how to use Preset UI primitives directly from assets/css/kit.css and assets/js/kit-interactions.js. The dashboard example uses illustrative data; the sign-in example validates the form in the browser without real authentication.

Serve the repository root using a local HTTP server and open examples/dashboard/ or examples/sign-in/. For a standalone export without repository-relative paths, use the Studio inspector's **Export .zip** action.
